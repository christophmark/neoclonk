# Neoclonk home-screen icon

High-resolution reconstruction of the original Clonk Rage C/R icon, created
with ImageGen from `original-content/release/cr_game_linux/icons/cr.png`.
The game artwork remains unchanged. The source image is retained here; public
exports are opaque PNGs: 180px Apple touch icon, 192/512px app icons, and a
512px Android maskable export with additional safe padding.

Original mark: RedWolf Design / Matthes Bender. This adaptation retains the
original content attribution and CC BY-NC 4.0 terms; see
`public/rage/licenses/clonk_content_license.txt` and trademark notice.

## Scenario-gallery background

`StartupMainMenuBG-HD.png` is an ImageGen-assisted higher-resolution restoration
of the original Clonk Rage mine-cart startup background. The menu serves a WebP
export; game sprites and scenario packs remain unchanged. Original composition
and artwork © RedWolf Design / Matthes Bender, CC BY-NC 4.0.
