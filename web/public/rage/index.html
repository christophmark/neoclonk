      Classic controls
      Q · PreviousW · SelectE · Next
      A · ThrowS · Up / jumpD · Dig
      Y / Z · LeftX · Stop / downC · Right
      Press a direction, then D. Your Clonk keeps digging diagonally downwards after you release the keys. X stops him. Solid rock and gold require explosives.
      Clonk Planet Hazard: Inventory (V) cycles carried items; Info (F) describes the selected item. Throw fires a weapon. Double Stop, then Throw, drops it. Some ammunition packs open with double Dig. On touch screens, extra action buttons appear automatically above the movement controls, using the selected Clonk’s original action labels. The crew-selection row hides when only one crew member is available, and returns for larger crews or open game menus.
      Each scenario keeps its original goals. Read the selected adventure’s description and follow its in-game objectives.
      In solo play, Save records the current round on this device. Load it from the main menu next time. Exit leaves the round and offers to save solo games. Selecting another scenario lets you start it or resume the current round. The − and + buttons zoom out and in using crisp pixel steps, from ¼× to 8×.
      Pause pauses the original engine. Escape opens its abort dialog. Y (German QWERTZ) and Z (English QWERTY) both move left.
