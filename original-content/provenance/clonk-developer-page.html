Developer Mode

How can I create my own objects or scenarios?

Clonk features an integrated developer mode which gives access to all script and graphics components of the game. In developer mode it is possible to modify existing objects and scenarios or create your own. Use the developer mode at your own risk. There is no support.

How the developer mode is activated depends on the Clonk game you are playing. In Clonk Endeavour, the developer mode can be activated in the options of the menu system. Clonk Rage features the same functions in a standalone editor, but only for Windows. On all platforms, however, you can unpack and modify the game content packages using the command line tool 'c4group'.

Newly created game content can be published and made available to other players, but you may not use the game content commercially if it was derived from and original game content or parts thereof. Original game content is covered by the licenses below.

3D Models

How can I create graphics for my own clonk types?

Available here is a fully animated 3D model of the clonk (as found in Clonk Rage) for the freeware 3D modeling software Blender (available for Windows, Linux, and Mac). This pack contains a script which permits creating the graphics for various clonk types including all typical animation phases. While this is not the same 3D model which has been used to create the original game content, the result comes the original extremely near.

Requirements: Blender, Python, some experience with 3D modeling and scripting.

Available clonk types: Clonk, Aquaclonk, HydroClonk, Inuk, JungleClonk, King, Knight, MagiClonk, Mage, Sorcerer, Skeleton.

Note: the clonk will look extremely rough when viewed in the modeling software. It has to look like this in order to produce the correct result when rendered at the extremely low resolution used in the game. This model is not suitable for rendering high resolution images such as titles or loader screens.

  • download Blender
  • Python Imaging Library PIL (required add-on)
